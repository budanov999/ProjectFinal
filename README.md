# Киномир - Одностраничный сайт

## Цель проекта

Разработать одностраничный сайт (лендинг) для демонстрации фильмов с использованием HTML, CSS и JavaScript. Сайт должен быть интерактивным, адаптивным и опубликованным в интернете, с возможностью переключения тем оформления.

## Технологии

*   **HTML:** Семантическая разметка.
*   **CSS:** Стилизация, адаптивность (Flexbox/Grid), переменные для тем.
*   **JavaScript:** Интерактивные элементы, динамическая загрузка контента, переключение тем с сохранением в `localStorage`.

## Обязательные разделы

*   Шапка с навигацией.
*   Главный экран с CTA.
*   Блок с карточками фильмов (динамическая загрузка).
*   Форма обратной связи с валидацией.

## Критерии оценки

*   Корректная структура HTML.
*   Реализованы обязательные разделы.
*   Использование Flexbox/Grid.
*   Реализована кнопка "Показать еще" или переключение темы с сохранением в `localStorage`.
